# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Agentic Evolution Harness team takes security issues seriously.

If you discover a security vulnerability within this repository, please **do not open a public issue**. Instead, follow responsible disclosure practices:

1. Send an email to `security@agentic-evolution.org` with:
   - A clear description of the vulnerability.
   - Steps to reproduce or a minimal proof-of-concept.
   - Potential impact on users or systems.
2. You will receive an acknowledgment within 48 hours.
3. We will collaborate with you to evaluate, mitigate, and release a patched version before public disclosure.

Thank you for helping keep our open-source community secure!
